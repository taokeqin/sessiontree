Native · local · open source

Every AI coding session
on your machine, one map.

A drill-down treemap of agents, projects and sessions, sized by tokens, cost or messages. Built with NSH and Rust. Nothing leaves your computer.

$ curl -fsSL https://taokeqin.github.io/sessiontree/install.sh | sh
Downloads the latest release, verifies its SHA-256 checksum, and installs to ~/Applications/Sessiontree.app. Run again to upgrade. Options
Map

Drill down

Agent → project → session. Click a tile to select, click again to open, or jump straight to a session from the right panel.

Measure

Tokens, cost, messages

Switch the metric without losing context. Built-in prices cover Claude, Codex, DeepSeek, GLM, Qwen, Kimi and more.

Find

Global search

⌘F searches every agent, project, session title, model and file path. Project pages include a searchable session list.

Share

Screenshots with redaction

Copy the window as a PNG with agent names, projects, session titles or numbers masked — then restored immediately.

Private

Local by design

Reads transcript files and SQLite stores. No account, no sync, no upload. Only a metadata cache is written locally.

Native

Three platforms

AppKit on macOS, Win32 on Windows, GTK 4 on Linux. Real window capture and system clipboard integration.
